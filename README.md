# 🎮 孖寶學字詞 - Kids Vocab Learning

一個為5歲小朋友設計既中英文詞彙學習遊戲網站！

## 🌟 功能

| 功能 | 說明 |
|------|------|
| 🃏 認字卡 |睇Emoji估中文/英文 |
| ❓ 估估吓 | 選擇題遊戲 |
| 🔗 配對 | Emoji配中文字 |
| ➕ 加字詞 | 自己添加新詞彙 |

## 📱 預設詞彙

應用程式內建以下五大詞庫類別：

- 📚 K2 第二段中文 — 中文詞彙（家庭、日常、情緒等）
- 🅰️ K2 第二段英文 — 對應英文詞彙
- 📚 K2 第三段中文 — 中文詞彙（自然、水、方向、形狀等）
- 🅰️ K2 第三段英文 — 對應英文詞彙
- 📖 Unit 2 — 英文默書句子練習

### ✏️ 自訂字詞

透過「加字詞」頁面新增，自動以 `localStorage` 持久化保存。
