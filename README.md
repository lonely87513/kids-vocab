| 功能 | 說明 |
|------|------|
| 🃏 認字卡 | 看 Emoji 猜中文/英文；完成一輪後可輸出結果截圖 |
| ❓ 估估吓 | 選擇題遊戲 |
| 🔗 配對 | Emoji 配中文字 |
| 🔊 音效 | 答對／答錯都有音效，頂部可一鍵靜音 |
| 🔀 反義配對 | K3 中文相反詞：揀兩個相反嘅字，啱就會消失 |
| ➕ 加字詞 | 自己添加新詞彙 |
| 📝 句子讀默 | 英文／中文默書句子練習 |

## 🗂️ 兩層分類（K2/K3 → 中文／英文）

四個遊戲（認字卡、估估吓、配對、句子讀默）都使用同一個三行式分類選擇器：

1. **第一行：學段** — `K2` / `K3` / `⭐ 其他`（大按鈕，高度 ≥44px）
2. **第二行：語言** — `中文` / `英文` / `其他`（依該學段實際有的子分組動態顯示）
3. **第三行：分類 chip** — 只顯示「該學段 + 該語言」底下的分類，窄屏可橫向捲動

切換學段或語言後，若原本選中的分類不在新組合內，會自動改選第一個可用分類；
重新進入遊戲時會保留上一次的選擇。

### 分類對應表

| 學段 | 語言 | 分類 |
|------|------|------|
| K2 | 中文 | 📚 K2第二段中文、📚 K2第三段中文 |
| K2 | 英文 | 🅰️ K2第二段英文、🅰️ K2第三段英文 |
| K3 | 中文 | 📚 K3第一段中文生字、📚 K3第一段中文詞語、📚 K3第一段中文默寫、📚 K3第一段中文相反詞、📖 K3第一段認讀句子 |
| K3 | 英文 | 🅰️ K3第一段英文、📖 Unit 2 |
| ⭐ 其他 | 中文／英文／其他 | 使用者自訂字詞的分類（按分類名稱自動判斷語言） |

分類樹由 `index.html` 內的 `CATEGORY_TREE` 統一管理，並提供以下 helper：

- `getCategoryTree()` — 回傳有序的「學段 → 語言 → 分類」結構
- `getCategoriesFor(gradeKey, langKey)` — 回傳該學段＋語言底下的分類
- `resolveCategoryLocation(cat)` — 回傳某個分類所屬的學段／語言
- `renderCategoryTabs(containerId, options)` — 四個遊戲共用的三行式頁籤繪製函式

## 🔊 音效

- 答對：上行三音（C-E-G）；答錯：柔和下行兩音，音量細，不會刺耳
- 用 **Web Audio API** 即時產生，**沒有外部音檔**、沒有 library，離線可用
- 覆蓋位置：認字卡測驗（✅／❌）、估估吓、圖文配對、反義配對
- 頂部有「🔊 音效開／🔇 音效關」開關，狀態會記在 `localStorage`

## 🔀 反義配對（K3 中文相反詞）

`📚 K3第一段中文相反詞`（14 個字、7 對）**不再使用一般認字卡／圖文配對**：

- 棋盤只顯示中文字，**完全沒有 emoji**
- 揀兩個字：**配對成功** → 兩張卡淡出消去、計分 +1、播答對音效；**配錯** → 卡片震一震並變紅、播答錯音效、卡片不會消失
- 棋盤上方顯示「揀兩個相反嘅字，啱就會消失」及「剩餘 N 組」；全部配對完成後顯示完成 modal
- 從認字卡選這個分類會自動切換到配對遊戲；切回其他分類即恢復一般玩法
- 詞庫資料不變，相反詞關係由「相鄰兩個為一對」於執行期推導

## 🗣️ Oral 口語（K3 英文）

新增的**句子填空（選字題）**玩法，主選單按鈕為「🗣️ Oral 口語」：

- 題庫分兩個分部（可隨時切換）：
  - **D. 高頻生字（Sight Words）— 30 題**：教材 D 段「認讀及運用高頻生字」的 26 個高頻字
    （I / he / she / am / is / the / of / and / are / we / they / you / a / to / in / it / yes / no /
    my / your / an / what / how / his / her / their），每個字至少有一題，覆蓋率 100%
  - **E. 口語對話（Oral）— 26 題**：完整保留教材 E 段 7 個題型
    （What's your name / How do you feel / How does he or she feel / Is it a or an __ /
    Are they __ / What are they + How many / What is it + What colour is it）
- 每題顯示一個句子（空格以黃色底標示）＋中文提示＋**6 個選字按鈕**（答案 + 5 個同類干擾字，位置隨機）
- **答對**：按鈕變綠並鎖定、其餘變淡、播答對音效、讀出填回答案後的完整句子、✅ +1
- **答錯**：按鈕變紅並震一震、播答錯音效、正確答案即時高亮、❌ +1（同一題不重複計錯）
- 完成畫面：分數、正確率、星星評級、錯題清單（原題 / 你的答案 / 正確答案 / 中文提示）
- 語音：「🔊 聽問題」讀出題目句子（空格讀作 "blank"）；「💡 中文提示」讀出中文提示；答對後自動朗讀完整句子
- 支援手機（390px）：選字按鈕可換行、觸控目標 ≥44px、無橫向溢出

## 📸 認字卡結果截圖

認字卡答完整一輪（進度 100%、顯示「完成!」）後，完成資訊區域會出現 **「📸 輸出結果截圖」** 按鈕：

- 圖片以 `<canvas>` 2D 手繪（1080 × 1350、4:5，2 倍像素比），**不引入任何外部 library**
- 內容：標題、日期時間、學習分類名稱、答對／答錯數、正確率、星星、錯題清單（最多 10 題）、專案名
- 星星規則：正確率 ≥90% → 3 粒、≥70% → 2 粒、其餘 → 1 粒
- 輸出流程：`navigator.share` 分享（iOS／Android）→ 否則下載 PNG → 兩者都不可用或使用者取消分享時，於頁面顯示結果預覽，提示「長按圖片即可儲存到相簿 📷」

## 📱 預設詞彙

應用程式內建以下十大詞庫類別：

- 📚 K2 第二段中文 — 中文詞彙（家庭、日常、情緒等）
- 🅰️ K2 第二段英文 — 對應英文詞彙
- 📚 K2 第三段中文 — 中文詞彙（自然、水、方向、形狀等）
- 🅰️ K2 第三段英文 — 對應英文詞彙
- 🅰️ K3 第一段英文 — K3 第一段英文詞彙（校園用品、問候、情緒、顏色、數字等，共 45 詞）
- 📚 K3 第一段中文生字 — 認讀生字 39 個（時間、季節、天氣、顏色等）
- 📚 K3 第一段中文詞語 — 認讀詞語 40 個 + Unit 3 補充 18 個，共 58 個
- 📚 K3 第一段中文默寫 — 默寫生字 21 個
- 📚 K3 第一段中文相反詞 — 相反詞 7 對（早晚、日夜、快慢、遠近、高低、黑白、冷熱）
- 📖 Unit 2 — 英文默書句子練習

### 📖 句子讀默（認讀句子）

- 📖 Unit 2 — 英文讀默句子（13 句）
- 📖 K3 第一段認讀句子 — 中文讀默句子（7 句，自動用粵語發音）

## 🧪 驗證工具

```bash
# 詞庫資料驗證（類別數量、重複字、欄位完整性）
node scripts/validate-vocab.mjs

# 兩層分類 + 結果截圖的端到端驗證（Playwright，需本機已有 chromium）
node verify-grouping.mjs

# 音效 + 反義配對的端到端驗證（Playwright）
node verify-sound-antonym.mjs

# Oral 口語（K3 英文）的端到端驗證（Playwright）
node verify-oral.mjs
```

`verify-grouping.mjs` 會自動啟動測試伺服器（127.0.0.1:8126）、執行 39 項檢查，
並把截圖輸出到 `.shots/`。`verify-oral.mjs` 執行 36 項檢查，同樣輸出截圖到 `.shots/`。
