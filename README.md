# 🎮 孖寶學字詞 - Kids Vocab Learning

[![GitHub Pages](https://img.shields.io/badge/deploy-GitHub%20Pages-brightgreen?logo=github)](https://lonely87513.github.io/kids-vocab/)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

一個為 5 歲小朋友設計的中英文詞彙學習遊戲網站！

## 🌟 功能

| 功能 | 說明 |
|------|------|
| 🃏 認字卡 | 睇 Emoji 估中文/英文 |
| ❓ 估估吓 | 選擇題遊戲 |
| 🔗 配對 | Emoji 配中文字 |
| ➕ 加字詞 | 自己添加新詞彙 |
| 📝 句子讀默 | 英文默書句子練習 |

## 📱 預設詞彙

應用程式內建以下十大詞庫類別：

- 📚 K2 第二段中文 — 中文詞彙（家庭、日常、情緒等）
- 🅰️ K2 第二段英文 — 對應英文詞彙
- 📚 K2 第三段中文 — 中文詞彙（自然、水、方向、形狀等）
- 🅰️ K2 第三段英文 — 對應英文詞彙
- 🅰️ K3 第一段英文 — K3 第一段英文詞彙（校園用品、問候、情緒、顏色、數字等，共 45 詞）
- 📚 K3 第一段中文生字 — 認讀生字 39 個（時間、季節、天氣、顏色等）
- 📚 K3 第一段中文詞語 — 認讀詞語 40 個 + Unit 3 補充 18 個，共 58 個
- 📚 K3 第一段中文默寫 — 默寫生字 21 個
- 📚 K3 第一段中文相反詞 — 相反詞 7 對（早晚、日夜、快慢、遠近、高低、黑白、冷熱）
- 📖 Unit 2 — 英文默書句子練習

### 📖 句子讀默（認讀句子）

- 📖 Unit 2 — 英文讀默句子（13 句）
- 📖 K3 第一段認讀句子 — 中文讀默句子（7 句，自動用粵語發音）

### ✏️ 自訂字詞

透過「加字詞」頁面新增，自動以 `localStorage` 持久化保存。
